## 실제 연결 검사

- 세 API 재수집: 정부24 목록 10,942건 / 지원조건 10,942건 / 중앙부처 복지 461건 / 충남 지자체 복지 337건. 출처별 갱신 성공.
- 출처·기관·지역으로 구성한 넓은 검색 후보 1,376개. 모두 신청 가능하다는 뜻은 아닙니다.
- 실제 Codyssey `gpt-5.4-mini`로 18개 후보 원문 분석, 중복 1개 통합 후 17개 결과. 검증한 요청에서 원문 분석 실패 0개.
- 사용자 정보 전송 미동의 요청은 공개 정책 분석 + 서버 비교로 처리됨을 확인.
- 동의 요청에서는 실제 AI 조건 대조 state, 원문 인용, 개인화 설명이 반환됨을 확인.
- 같은 사용자에게 방문/온라인 가능 여부만 반대로 바꾼 두 실제 API 요청의 추천 ID 순서가 동일함을 확인.
- 만 65세 미만, 구형 편의성 가중치 요청, 다른 Origin 요청, 자유입력 AI 미동의 요청이 거부됨을 확인.
- 작업 기록 삭제 후 해당 작업 조회가 404가 되는 것을 확인. 사용자 정보를 DB에 저장하지 않음.

## 한계

원문 인용 존재 검증은 모델의 의미 해석 정확성을 보장하지 않습니다. 최종 수급 자격·선정·예산·접수 가능 여부는 담당 기관이 확인해야 합니다. 전체 후보를 한 번에 모두 분석하지 않고 이번 검토 수를 화면에 표시합니다. 정책 분석 실패 시 추측한 결과 대신 분석 대기로 표시합니다.

PWA 로컬 실행 버전입니다. APK/iOS 패키징·외부 HTTPS 배포·실제 어르신 현장 평가·실제 신청 접수는 하지 않았습니다. 소형모델은 학습하지 않고 해당 역할을 LLM으로 대체했습니다.
